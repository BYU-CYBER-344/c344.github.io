In this homework you will select, prepare, and test your platforms of choice for virtual machines and containers. You will use these platforms (VM and container) throughout the semester.

Options for Virtual Machines:
* VMWare running on a lab computer.
* ProxMox running on your own x86 computer.
* Microsoft Hyper-V running on your own Windows computer.
* UTM running on your own MacOS (Apple) computer.
* Amazon Web Services EC2 using AWS Academy ($50 credit for the semester).
* More options coming
* Any option of your choice that meets the requirements of the class.

Options for Containers
* Docker Desktop running on a lab computer.
* Docker Desktop for Windows running on your own computer.
* Docker Desktop for MacOS running on your own computer.
* Docker Desktop for Linux running on your own computer.
* Docker running on an AWS EC2 instance from AWS Academy.
* More options coming
* Any option of your choice that meets the requirements of the class.

More details for this homework, including the requirements for your platforms will be posted here before the first day of class.
